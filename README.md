
# Calm - Terminal Mindfulness Helper

Calm is a simple Python terminal application designed to help users relax through guided breathing exercises and inspirational quotes.

## Features

- Displays random inspirational quotes.
- Provides guided breathing exercises.
- Uses a default 4-4-6 breathing pattern.
- Allows users to customize inhale, hold, and exhale durations.
- Supports customizable breathing rounds.
- Displays a countdown timer for each breathing phase.
- Provides a simple interactive terminal menu.
- Uses Python's built-in standard library.

## Requirements

- Python 3.8 or newer.
- A terminal or command prompt.
- No third-party packages are required.

## Installation

1. Clone this repository or download the project files.
2. Install Python 3.8 or newer if it is not already installed.
3. Open a terminal in the project directory.

## How to Run

Run the following command:

```bash
python calm.py
```

On some systems, use:

```bash
python3 calm.py
```

## Menu Options

1. Guided breathing with the default 4-4-6 pattern.
2. Display a random calming quote.
3. Customize breathing durations and rounds.
4. Exit the application.

## Default Breathing Pattern

- Inhale: 4 seconds
- Hold: 4 seconds
- Exhale: 6 seconds
- Rounds: 4

## Customization

Choose option 3 from the menu to customize the inhale duration, hold duration, exhale duration, and number of rounds.

Enter a positive integer for each setting. Press Enter to use the default value.

## Stopping the Program

Press Ctrl+C to exit the application.

## Disclaimer

Calm is a basic mindfulness practice tool. Breathe comfortably and do not force your breathing or hold your breath if you feel uncomfortable.
